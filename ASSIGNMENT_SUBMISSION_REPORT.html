Section 4: Subagent Architecture Design (Deliverable B)

The review bot uses a modular multi-subagent pipeline:

  • Explore Subagent: Generates high-level semantic PR summary without flooding token context.
  • Plan Subagent: Filters non-code assets and dynamically routes relevant diffs to specialized reviewers.
  • Security Subagent: Detects secret leaks, auth bypasses, and injection risks.
  • Logic Subagent: Identifies formula inversions, off-by-one errors, and invariant regressions.
  • Test Coverage Subagent: Enforces unit tests on newly added functions.
  • AutoFix Subagent: Generates ready-to-apply diff patches for safe deterministic issues.
